Primary User Flows
Renter — Book Gear
01
/
Homepage
Enter location + gear type in search bar
02
/gear
Search Results
Filter by condition, price, radius. Select a listing.
03
/gear/[id]
Listing Detail
Review specs, photos, lister, calendar. Select dates.
04
/sign-in or /sign-up
Authentication
If not signed in — redirected back to listing after auth.
05
/gear/[id]/book
Booking Request
Review full cost breakdown. Add optional message.
06
/gear/[id]/checkout
Payment
Stripe card entry. Confirm charge + deposit hold.
07
/gear/[id]/booking-confirmed
Confirmed
Full address revealed. Message lister to coordinate.
Lister — Publish First Listing
01
/sign-up
Create Account
Clerk auth → profile setup → select "List gear"
02
/lister-onboarding
Lister Onboarding
ID verification (Stripe Identity) → bank account (Stripe Connect) → lister agreement
03
/dashboard/listings/new
Create Listing
10-step wizard: category → specs → condition → photos → pricing → deposit → availability → location → publish
04
/gear/[id]
Live Listing
Listing now searchable. MSRP ≥ $5K goes to admin review first.
Rental Lifecycle — Pickup to Payout
01
/dashboard/messages/[id]
Pre-Pickup Messaging
Renter + lister coordinate address, pickup time, gear tips.
02
/dashboard/bookings/[id]
Pickup Day
Renter confirms gear as described — or flags condition issue. Lister confirms handoff.
03
/dashboard/bookings/[id]
Active Rental
Return countdown. Renter can request extension or early return.
04
/dashboard/bookings/[id]
Return Day
Lister inspects — confirms clean or files damage claim. Renter confirms returned.
05
/dashboard/bookings/[id]/review
Leave Review
Both parties review. Blind — revealed after both submit.
06
/dashboard/earnings
Payout
Lister payout released after 48h dispute window. Deposit released to renter.
Admin — Dispute Resolution
01
/admin/disputes
Dispute Queue
Prioritized by type and SLA. Damage → Late return → Pre-rental.
02
/admin/disputes/[id]
Evidence Review
Compare pickup vs. return photos. Read message thread. Review both statements.
03
/admin/disputes/[id]
Issue Ruling
Ruling wizard: select outcome → amounts → explanation → preview → confirm. Triggers Stripe disbursements.
04
/dashboard/bookings/[id]/review
Reviews Unlock
Both parties notified. Reviews available for 14-day window.
