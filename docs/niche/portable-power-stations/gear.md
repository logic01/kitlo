# Portable Power Stations — Gear

Phase 1 bundle add-on only (standalone foreclosed by Hygglo / FriendWithA / ShareGrid). Bundled with overlanding and hunting bookings. UL 9540 / UL 2743 certification required; major brands only (Jackery, Goal Zero, EcoFlow, Bluetti, Anker Solix). Units >1,000Wh: owner-driven local handoff only (UN3480/UN3481 hazmat — no renter shipping).

## Prohibited

- Uncertified white-label Li-ion stations (no UL 9540 / UL 2743)
- Lead-acid batteries of any form factor (AGM, flooded, gel) — LFP-only platform
- Units >1,000Wh shipped by renter (UN3480/UN3481 hazmat — owner-driven local handoff only)
- DIY battery builds / homebrew BMS packs
- Damaged / over-discharged / thermal-event-history units
- Standalone power-station listings outside of bundle context (Phase 1 policy)
