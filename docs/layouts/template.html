How it works
01
Find the gear
Search by location and type. See the full spec sheet, condition grade, and lister profile on every listing.
02
Book and pay
Deposit held on card. Releases to lister at confirmed pickup. Renter Protection Plan covers damage up to $5,000.
03
Hunt. Return. Done.
Both parties confirm return in the app. Deposit released. Ratings left on both sides.
Condition rating system
Mint
Barely used. No visible wear. Functions exactly as new. Rental history backs it up.
Field-Ready
Used on real hunts. Body wear possible — scratches on chassis, not glass. Fully functional.
Battle-Scarred
Veteran gear. Shows its history. Priced accordingly. Performance intact. Read the lister's notes.
